# Health Insurance Awareness & Advisory Experience

A premium bilingual (English + தமிழ்) health insurance awareness web platform built with Next.js, Tailwind CSS, Framer Motion, and Three.js.

## Key Features
- **Bilingual Experience**: Seamless English and Tamil (தமிழ்) localization.
- **Stage 1 (Profile & Household)**: Interactive constellation questionnaire with household modeling.
- **Stage 2 (Single 'What If?' Scenario)**: Personalized medical emergency scenario based on real profile members.
- **Stage 3 (Educational Explanation)**: 5-chapter visual breakdown of modern health insurance mechanisms, claim journeys, coverage boundaries, and digital policy clauses.
- **100% Client-Side Privacy**: Zero backend databases, zero external persistence. All user data is preserved strictly within active browser session state (`sessionStorage`).

## Tech Stack
- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS (Obsidian Plum Design System)
- **Animation & 3D**: Framer Motion & Three.js
- **Runtime**: Client-side single-page architecture

## Development & Build
```bash
# Run local development server
npm run dev

# Run production build
npm run build
```
